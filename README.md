# [GTA-6-FPS-Calculator](https://exactfps.com/gta-6-fps-calculator/)
GTA 6 FPS Calculator
We compare your graphics card’s PassMark G3D score with a reference card (GeForce RTX 4070). We then scale the result for resolution and graphics preset. The reference point is an assumption, not a measurement, because no GTA 6 PC benchmarks exist. We will replace it with real data when the PC version is released and tested. Read the full steps in “How this estimate is calculated” inside the calculator.
